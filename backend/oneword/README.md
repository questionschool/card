# 올해의 한 단어 DB

프런트엔드는 `/oneword.html`, 자산은 `/oneword/`입니다. GitHub Pages에서 정적으로 실행되며 OpenAI, ChatGPT, Sites 로그인이나 구독이 필요하지 않습니다.

Google Apps Script 웹앱에 `text/plain` POST로 직접 연결합니다. 배포는 소유자 권한으로 실행하며 접근은 모든 사용자입니다. 지정한 Google Sheets DB만 코드에서 사용하며 시트 파일 자체는 비공개로 유지합니다.

기록·참여자·단어목록·운영안내·지지 탭으로 관리합니다. 단어목록에 행을 추가하면 사이트 방문 시 다시 읽어옵니다.

브라우저가 생성한 무작위 수정키는 로컬 저장소에 보관하고, DB에는 SHA-256 해시 소유자ID만 기록합니다. 같은 브라우저에서 자기 기록을 수정·삭제할 수 있습니다. 개인 회고는 공개 목록 API에 포함하지 않습니다. 뜻풀이 수정은 개인 기록에만 반영됩니다.

하트는 다른 사람의 공개 기록에만 한 번씩 저장되고 취소할 수 있습니다. 기존 공개·소유권 설정은 유지하며 기록 삭제 시 연결된 지지도 삭제됩니다. 공유 썸네일은 `/oneword/share.png`에 있습니다.

Apps Script 수정 시 기존 웹앱 배포를 새 버전으로 갱신합니다. 배포 URL이 바뀌면 `oneword/app.js`의 SHEETS_WEB_APP을 갱신합니다.
